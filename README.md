# Invoice Generator

Private, offline macOS invoice generation for Codernetic.

## Development

The repository's package scripts run with the Node.js version in `.node-version`, even when the
host uses Vite+ system-first mode. Read the [harness guide](docs/harness/README.md) before setup,
validation, Electron verification, packaging, or handling test evidence. It contains the current
bounded commands, macOS launch-permission rule, output locations, and failure guide.
